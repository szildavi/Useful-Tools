# QR-code generator

## About

A web-based qr code generator that is able to generate qr code.

## Requeriments

- It should be able to generate qr codes within a website.
- It should have different square types, such as round and square.
- It should be able to use different colors.
- It should be able to use logos with different types of image format such as .jpg or .png
- It should be able to export as an image, with high quality.
- It should be able to generate different size.
