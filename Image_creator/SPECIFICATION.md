# Image creator

## About

This is an web-based image creator, that is able to create images, within grids for example printing, with parameters.

## Requeriments

- It should be able to use multiple image to arrange images with scaling. For example someone wants print 4 a1.png and 1 a2.png within the same paper, then it should scale it automatically.
- It should be able to export out as a png, jpg and pdf.
