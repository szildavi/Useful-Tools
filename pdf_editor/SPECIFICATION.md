# PDF editor

## About

A web-based PDF editor, that is able to convert, export and edit pdf files.

## Requeriments

- It should be able to convert from different types of file to pdf and from pdf to different types(If it's possible). Such as docx, xslx, pptx, txt, odt, odp, ods
- It should be able to edit texts in the pdf, if it's possible.
- It should be able to show the pages of the pdf.
- It should be able to merge, split pages.
- It should be able to delete pages.
- It should be able to draw to the pdf.
- It should be able to export to pdf.
- It should be able to sort the pages as the user wants.
- Privacy is the first!
