# Ultimate Converter

## About

A Ultimate Converter both application and web that is able to convert a tons of .file type to a other compitable type. The language that you write is up to you, but I think a python, with tkinter. It should be compatiable with both linux and windows.

- It should make an application and a website. The application should have more file types that is not be able to convert within the website. The websites won't have a backend, so in there should be only those, that is able to convert within a browser.
- It should be able to convert the conversions that is compatiable. The types is in the CONVERSIONS.md, those should be there, but if you have more useful conversion than feel free to add it.
- It should be able to work it with multiple files.
- If there is multiple file, then it should work paralel that is depends on the user's CPU core number.
- It should be able to option, to controll the convertion if there is more option. For example a video convertion from .mp4 to .mov.
- If it's possible, converting from and back too for formats.
